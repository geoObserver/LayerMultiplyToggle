about=(26.05.2026) Adds a toolbar button that toggles the Multiply blend mode for all layers or only the selected layers/groups. A clickable Multiply icon next to each layer in the layer tree toggles Multiply per layer. Right-clicking the toolbar button resets everything (restore originals, remove icons, toggle off). Original blend modes are preserved and restored on toggling off, and the on/off state is stored per project. Compatible with QGIS 3.x (Qt5) and QGIS 4.x (Qt6).
