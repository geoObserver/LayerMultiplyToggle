about=(26.05.2026) Adds a toolbar button that toggles the Multiply blend mode for all layers or only the selected layers/groups. The same apply/restore actions are available from the layer-tree right-click menu (QGIS 3.32+). Original blend modes are preserved and restored on toggling off, and the on/off state is stored per project. Compatible with QGIS 3.x (Qt5) and QGIS 4.x (Qt6).
